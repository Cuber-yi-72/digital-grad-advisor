# 工科数字研究生导师

给研究生用的 AI 工具包：给自己配一个数字导师，日常陪练科研与研究生生活（怎么学、怎么汇报、组会、实验、论文、出路）。许可：**MIT**（见 [LICENSE](LICENSE)）。

面向：**材料 / 电子 / 机电等工程学科**。交互：**中文**（论文相关可中英对照）。

> 定位：**补位不替代。** 数字导师帮你把问题问清楚、把下一步拆开、挡住低质量方案；方向、经费、署名、送审、能不能毕业，仍由你的真人导师决定。

| 模块 | 作用 |

直接说「这周实验全失败了」「开题不知道创新点在哪」，它按 skill 带你，不必会写 prompt。

先翻 [03-模板/研究生生涯手册.md](03-模板/研究生生涯手册.md)。技能索引：[skills/README.md](skills/README.md)。

## 10 分钟开始

1. 复制 [00-核心/SYSTEM.md](00-核心/SYSTEM.md) 全文当系统提示。
2. 填 [01-配置/学生档案.md](01-配置/学生档案.md)（你自己）。
3. 按你知道的填 [01-配置/实验室档案.md](01-配置/实验室档案.md)（组里有什么设备、组会怎么开、老师讨厌什么样的 PPT）。不确定就留空，对话里再补。
4. 按 [使用手册.md](使用手册.md) 接到你常用的模型。
5. 深度任务再上传对应 `skills/<name>/SKILL.md`。

中文目录乱码时，解压后跑 `python scripts/init-ascii-links.py`。Custom GPT 若截断：先贴 SYSTEM §0–§5.1 与 §9，红线用 `边界与红线.md`。

想备份：自己 `git init` 推到**私有**库。zip 没有 git remote；没有 remote 时回收规则不会删改造层。

红线：[00-核心/边界与红线.md](00-核心/边界与红线.md)。
