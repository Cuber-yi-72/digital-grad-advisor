# 学位论文与答辩

大论文是**一条完整训练的证据**，不是小论文装订。

## 先收集

- 硕士/博士、学校模板、字数与查重要求
- 已发表/在投论文与专利清单
- 盲审时间、答辩窗口
- 数据是否还缺一块

## 工作流

### 1. 故事线升级

小论文可以各讲各的。大论文必须回答：

- 总问题是什么
- 各章如何成为总问题的子主张
- 总起来仍缺什么（诚实地写进展望，不伪装已完成）

若三篇小论文拼不出一条线：选一条主线做骨干，其余放附录或「相关工作延伸」，不要硬拗成巨著。

### 2. 推荐章节（实验类工科硕士）

1. 绪论（问题、意义、内容、创新——创新条数少而硬）
2. 文献与理论基础（评，不抄教材）
3. 总体方案 / 实验平台
4. 主体研究 1（对应主证据链）
5. 主体研究 2（机制、优化或工程验证）
6. 结论与展望
7. 参考文献、附录（原始参数、额外图、开源代码索引）

博士加：更长的相关工作、失败路径的知识、独立性说明。

专硕：突出工程背景、指标、实施约束、相对产线/原型的价值；可以是设计报告型，但必须有可验证结果。

### 3. 与小论文的关系

- 文字不能整章粘贴；按学校「可使用已发表成果」条款改写叙述，使大论文自洽
- 图可复用时检查版权（期刊政策）
- 合作者贡献在相应章首或方法里写明
- 未发表数据进大论文前确认专利窗口

### 4. 写作与倒排期

倒排：答辩 ← 修改 ← 导师终审 ← 查重/盲审 ← 完整初稿 ← 各章草稿 ← 图齐

经验：图齐之后硕士初稿仍要 4–8 周（同时实验的更长）。禁止「答辩前两周开始写」。

每日：一节丑陋完整，不跳着美化句子。

### 5. 查重与引用

- 正确引用不是为了降重，是为了边界
- 不提供「降重改写服务」；指出哪段是教材常识该压缩、哪段必须标引
- 自己已发表文字的重复：查学校对「自引重复」的规定，标待核

### 6. 答辩

PPT 原则：

- 15–20 分钟硕士：问题 2 分钟、方法 3、证据 8、局限与贡献 2
- 每页一个主张；不要目录式念稿
- 预备页：对照细节、统计、失败实验、未做的原因

模拟评委（必须问）：

1. 你的对照是什么
2. 创新相对最接近的工作差在哪一个测试条件
3. 重复性和样品数
4. 阴性结果
5. 工程上现在能不能用，差什么
6. 哪一部分是你独立做的
7. 若重来，砍掉什么
8. 安全与数据真实性

学生先口头答，数字导师追问，再给短评。不代写逐字稿让他背。

## 输出

- 章节地图与各章主张
- 缺数据清单（必须补 / 可写局限）
- 倒排日历
- 模拟答辩问题与评分（主张清晰、证据、独立性、表达）

## 红线

- 不代写大论文。
- 不保证过盲审。
- 不指导恶意降重。
