# 汇报与组会 · 改造层

先读：

1. `03-模板/研究生生涯手册.md` 第二、三章（怎么汇报、开组会）。
2. `vendor/academic-pptx-skill/content_guidelines.md` — 行动标题、一页一图、超时、结论页留屏。组会默认 **Structured Argument**。可省略公开报告才要的 References 页；**不可省略**条件、对照、样品号。

需要完整周报纸质结构时用 `03-模板/周报.md`。无 vendor/pptx：仍用行动标题、一页一图、超时第一过错、结论页留屏；不要调用不存在的 PPTX 脚本。

## 周报（书面）

六块：主张 / 证据 / 对照上周 / 失败 / 下周时间盒 / 请决定 ≤2（A/B+建议）。

改写规则：工时 → 主张。藏阴性结果 → 拉出来放第 4 块。没数据也要交，写探针。

## 组会 PPT（口头）

页数：学徒 5；常规 6–8；公开组会或中期按档案。每页标题做 **ghost deck 测试**。

推荐页：

1. 上次决定执行了没有（1 页，强制闭环）
2. 本周假设（可证伪的一句）
3. 条件与对照（可被挑刺）
4. 证据（原始，含失败；一页一图）
5. 替代解释
6. 下一步 + 请决定 A/B

上游「Answer First」适合时间紧的一对一：先结论再证据。

预审清单（完整勾选版 `03-模板/组会检查清单.md`）：

- [ ] 标题是结论不是栏目
- [ ] 图 30 秒能读懂（轴、单位、条件、n）
- [ ] 阴性结果不藏在最后
- [ ] 按时长排练，少 1–2 分钟
- [ ] 结尾是请求，结论页留着
- [ ] 安全问题单独说，不混在闲聊

给 5 个恶评委问题，让学生先答。

## 听会与会后

学生若不是主讲人：给他 2 个针对别人报告的具体问题。  
会后当天写决定本（一对一进门 3 句与决定本可用 `03-模板/一对一汇报提纲.md`）。下一次周报第一行引用。

## 输出

周报六块草稿（学生填数字）或 PPT 行动标题序列 | 恶评委 5 问 | 请导师决定的 1–2 项 | 会后行动项表

## 红线

不替学生编进展。不代表导师发通知。不把组会做成视觉动画展示。
