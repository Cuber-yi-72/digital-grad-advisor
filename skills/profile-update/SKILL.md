# 配置与标签更新

配置文件**可以、也应该**改。Skill 正文里的默认（放养、周报结构、组会页数）低于这些文件：

| 文件 | 改什么 |
|------|--------|
| `01-配置/标签与证据.md` | 性格、氛围、习惯等短标签 + 证据 + 曾用值 |
| `01-配置/实验室档案.md` | 设备、政策、组训、反例（事实字段） |
| `01-配置/学生档案.md` | 该生目标、基础、课题现状 |
| `01-配置/培养时间线.md` | 学校硬节点日期 |

本 skill 专管**标签冲突与修订**。改设备名单等事实字段时直接改档案并在变更日志留一行。

## 何时触发（主动，不必等用户说「改标签」）

- 用户明确：他不是压榨、组会其实只要一张图、我不是拖延……
- 你观察到：学生用「压榨」描述，但具体情节是骂完给方案、帮改对照、会后加班一起看数据 → 更像 `刀子嘴豆腐心`
- 连续两次组会描述与「放养」或「必须每天打卡」不符
- 学生出路从「一定读博」变成「先就业」

## 工作流

### 1. 读当前值

打开 `标签与证据.md`，找到对应键。没有该键就新建，不要改 skill 默认来冒充。

### 2. 写证据，不先改结论

追加一条证据，含：日期、原话或可观察行为、你的解读（标明是解读）。

### 3. 出示对比（必须让人看见）

```text
【标签修订提议】
对象：导师 / 沟通风格
当前值：压榨（来源：学生入学自述）
建议改为：刀子嘴豆腐心
依据：……（2 条以内）
若改成新标签，我以后会：组会仍按高标准预审，但教你带走决定、不教你躲或对抗。
请回：同意改 / 先观察 / 保持旧标签
```

### 4. 落盘

- **同意**或已有 2–3 条独立证据：当前值←新值；旧值进曾用；状态=生效；变更日志加一行。真的用编辑工具改文件，不要只在聊天里说改了。
- **先观察**：状态=待确认；辅导暂用「按新值小心行事」，并在回复里写「标签尚未改」。
- **保持旧值**：只加证据，不改当前值。

### 5. 改完后的行为

立刻用新标签调整策略，例如：

| 新标签 | 辅导怎么变 |
|--------|------------|
| 压榨 | 边界、最小交付、书面确认工作量 |
| 刀子嘴豆腐心 | 预审加严；提醒骂≠否定课题；会后抓决定 |
| 放养 | 逼学生自己定周问题，数字导师补结构 |
| 完美主义拖延 | 强制丑图周五截止 |
| 盲目开做 | 强制先写主张与对照 |

## 禁止

- 偷偷改标签不告诉学生/导师
- 用新标签否定安全、诚信红线
- 把「严格」一律写成「压榨」，或把克扣骚扰写成「刀子嘴」
- 改 GitHub 上游 skill 来迁就某位导师的性格——性格只活在配置里
