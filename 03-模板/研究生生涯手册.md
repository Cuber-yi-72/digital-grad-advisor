# 研究生怎么当（学生手册）

给工科硕士/博士。这是课题组默认的**隐性课程**。数字导师按此带你；实验室档案若有冲突，以实验室档案为准。

研究生训练同时走 **三条线**，缺一条都会在某学期爆：

| 线 | 学的是什么 | 每周要有的痕迹 |
|----|------------|----------------|
| A 手艺与问题 | 实验/仿真、文献、把方向收成可检验问题 | 原始数据或精读笔记 |
| B 被指导 | 周报、组会、一对一：让导师能做决定 | 一页主张+证据 |
| C 出路 | 英语、表达、专利/项目叙事、信息网 | 再小也要有固定小时 |

本科习惯是「把老师布置的做完」。研究生习惯是「自己提出下周该验证什么，带着证据来被打」。

## 一、从入学起应该怎么学习

### 1. 你现在处在哪一段（先对号）

| 段 | 大约何时 | 学习目标 | 合格样子 |
|----|----------|----------|----------|
| 学徒 | 入学 0–6 月 | 活在实验室里：安全、设备、组内论文、怎么被指导 | 能独立预约一台核心设备；能讲清组内 3 篇代表作的主张和对照 |
| 收口问题 | 6–12 月 | 把「导师给的方向」收成问题卡 | 开题不是形容词，有对照、判据、备路 |
| 主实验 | 开题后到中期 | 一条证据链做完，失败也记录 | 每周至少一张带条件的图 |
| 产出 | 中期后 | 论文/专利故事线，砍支线 | 能 8 分钟讲完贡献边界 |
| 收尾 | 最后一学期 | 大论文、答辩、出路 | 数据可归档，出路有时间表 |

跨考、专硕、博士只改节奏，不改这五段。专硕把「工程指标与实践」提前嵌进收口问题；博士把学徒拉长，但第 1 年末必须有可证伪的小问题，禁止「毕生课题」。

### 2. 四种学习，权重会变

1. **课程**：服务课题与学位杠。映射到开题里会出现的公式/标准。考前两周及格线，不要用满课逃避进组。
2. **文献**：不是下载。扫/读/啃三层；每篇问 WHY/HOW/WHAT；指标必须带测试条件。
3. **手艺**：看一次 → 帮手 → 独立做并写记录 → 能教下一个人。不会的操作不要装会。
4. **被指导**：组会和周报本身就是训练。不会汇报 = 研究能力缺一块，不是「表达差而已」。

学徒期比例建议（可改）：课程 30% / 文献 20% / 手艺 35% / 被指导 15%。  
主实验期：课程趋近 0 / 文献 15% / 手艺 60% / 被指导 15% / 出路暗线 10%（从文献里挤）。

### 3. 研究生的学习循环（比「再看一遍课件」有用）

```text
本周问题（一句话，可证伪）
    → 最小动作（实验 / 精读 / 推导 / 仿真，时间盒）
    → 证据（图、表、失败现象，条件写全）
    → 解释或证伪
    → 写进周报
    → 组会被问
    → 改下周问题
```

没有「本周问题」的一周，叫在实验室出现，不叫学习。

### 4. 问人与自己扛

- **48 小时规则**：卡住先自己查 SOP、旧实验记录、组内论文 Methods，写清「我试了什么、卡在哪一步」。48 小时仍卡，带这张纸去问。
- 问师兄：一次一个具体操作（「XRD 样品台怎么放」），不要「有空教我吗」。
- 问导师：一次最多两个要决策的问题，每个带 A/B 和你的建议。
- 同样的问题不要每周换措辞问一遍——说明你没执行上次的决定。

### 5. 必须建立的三个本子（电子即可）

1. **实验/仿真记录**：当天写，批次号、方法文件、原始路径（模板：`实验记录.md`）。
2. **文献矩阵**：一行一篇，禁止只收藏不填。
3. **组会决定本**：导师原话里的决定 + 截止日期 + 证据。下周周报第一行引用它。

英语：当工具练（精读、图注、口头 2 分钟），不要只报名班。出路若是出国，从第 2 学期起每周固定小时，否则会被实验吃掉。

### 6. 常见学法错误

| 错误 | 换成 |
|------|------|
| 把文献当进度（下了 80 篇） | 本周啃 1 篇能复述 Methods |
| 完美主义不肯出丑图 | 周五必须有一张条件写全的丑图 |
| 课程第一、进组以后再说 | 进组从第 2 周就开始 |
| 只做师兄吩咐的步骤，不问为什么 | 每个步骤对应哪句假设 |
| 失败了重做但不记录 | 失败分类后再做最小检验 |
| 等「想清楚了再去组会」 | 带着不清楚去组会，这正是组会的用处 |

## 二、怎么汇报（周报 / 一对一 / 微信）

导师要的不是你很忙，是**能做决定的信息**。

### 1. 周报：一页，六块（模板：`周报.md`）

1. 本周主张（验证/证伪了什么）  
2. 证据（一张图，条件写全）  
3. 对照上周计划（没做成写原因：设备 / 设计 / 我拖延）  
4. 失败与无效实验  
5. 下周三个时间盒  
6. 请导师决定 ≤ 2 项，每项 A/B + 你的建议  

禁止：只有工时没有结论；藏阴性结果；一次提 8 个问题。

没进展的一周更要报：对照做了吗、探针看到什么、下一个最小检验是什么。藏起来只会让下一次更惨。

### 2. 一对一（15–20 分钟）

进门前 3 句话：

1. 上次您让我验证 X，结果是……  
2. 我需要您今天拍板的是 A 还是 B（我建议 A，因为……）  
3. 若设备/时间不够，最小交付改成……是否接受？

带一张图的打印或投屏，不要现场翻文件夹。结束时口头复述决定，当天写进组会决定本。

### 3. 微信 / 邮件（默认短）

```text
【请求】周五前确认是否外送 XPS（约 2 周）
【事实】对照样品 n=3 已完成；实验组重复失败，记录见附件图 1
【我建议】先外送 2 片，同时加对照片
【不需要您做的】本周制备我自己排
```

不要凌晨发长语音。紧急安全除外。未公开配方不要发公共网盘。

### 4. 汇报语言

| 不要 | 要 |
|------|----|
| 我这周做了很多实验 | 我验证了「温度升 20℃ 磨损下降」——未观察到，n=3 |
| 表征还没排上，所以没进展 | 制备完成；表征排队至周四；桌面工作：把上周 XRD 拟合成表 1 |
| 师兄说这样行 | 与师兄 3 月样品同条件，我这批差在气氛（记录第 4 行） |
| 我想发顶刊 | 当前证据链能支撑的主张是……差的数据是…… |

## 三、开组会应该注意什么

组会有三种角色，都要会：**讲的人、听的人、被问的人**。

### A. 你讲的时候

1. **超时是组会第一过错。** 按实验室档案的时长排练，目标少 1–2 分钟。
2. **标题写结论，不写栏目。**  
   不要「实验结果」；要「在 200℃、n=3 下未观察到耐磨提升」。  
   只读标题应能听懂故事（ghost deck）。
3. **结构（学徒 5 页，之后 6–8 页）：**  
   问题与本周假设 → 条件（别人能挑刺的那些）→ 证据（原始感：含失败）→ 解释与替代解释 → 下一步与请求。  
   新同学第一学期允许 1 页「我学会了什么操作」。
4. **一页一张图。** 轴、单位、条件、误差含义、样品号。论文图不要直接截 PDF。
5. **阴性结果放中间，不要最后秒提。** 组会就是来修方案的。
6. **结尾不是谢谢。** 结尾是结论 +「请决定 A/B」。结论页留在屏幕上接受提问。
7. **每页最多约 40 字正文。** 你讲，幻灯片举证。不要念稿。
8. **会前把数字导师当恶评委**：主张可证伪吗？图 30 秒能读懂吗？有没有把求助包装成成果？安全有没有藏着？

学术幻灯片的完整标准见上游 `vendor/academic-pptx-skill/`（行动标题、一页一图、不超时）。组会比会议更短、更要原始数据。

### B. 别人讲的时候（这是被很多人浪费的训练）

- 合上电脑购物；打开笔记记：**他的假设、对照、你听不懂的一步**。
- 每人至少准备一个**具体**问题，例如「对照和实验是不是同一天制备的」，不要「讲得真好」。
- 师兄的失败比成功更值得记：避免你下周重复。
- 导师插话时记下**决定**，不只是语气。

### C. 被提问的时候

- 听完再答。听不清就请对方重复。
- 三种诚实答案：数据在第 X 页 / 我没做，原因是……，计划…… / 我不知道，会后补。
- 不要为了面子编参数。被戳穿比「我不知道」毁信任得多。
- 争执针对主张和条件，不针对人。被批到实验设计，回去改设计，不要改心情。

### D. 组会后 24 小时

写：决定、行动项（谁/何时/何证据）、可能的误解（「我以为让我换题」→ 标待确认）。  
下一周周报第一行必须引用这次决定。没有闭环，组会就是表演。

### E. 组会禁忌

- 只有目录和背景、没有本周数据  
- 把别人的图当自己的进展  
- 隐藏安全险情  
- 超时还翻新支线  
- 当场承诺做不到的「下周发顶刊」  
- 嘲讽同学的阴性结果

## 四、三年能力成长（生涯主线，不是只在毕业学期找工作）

把「以后当什么」嵌进每周，否则会被实验吃掉。细节决策走 IDP skill；这里只订**每年该长出的能力**。

### 硕士（示例，按学校节点改日期）

| 学期 | A 手艺与问题 | B 被指导 | C 出路暗线（每周固定小时） |
|------|----------------|----------|---------------------------|
| 入学前–T1 | 组内 3 篇、安全、一台设备 | 第一次周报、听懂组会 | 想清楚约束（地域/读博/必须工作） |
| T2 | 预实验、问题卡草稿 | 能 5 页讲完预实验 | 英语阅读提速；列 3 个可能去向 |
| T3 开题 | 开题合同：对照+备路 | 开题答辩像组会加长版 | 若出国：语言考试占表；若就业：项目叙事开始积累 |
| T4–T5 | 主证据链、中期、论文/专利窗口 | 8 分钟讲贡献边界 | 简历条目用「问题-方法-指标」；实习须导师同意 |
| T6 | 大论文、归档 | 答辩 | 投递/套磁按窗口，不和答辩抢最后两周 |

博士：第 1 年末小问题闭环；第 2 年主问题；会议报告当成组会的公开版。

### 每年只补一个表达短板

口头 2 分钟 / 一页周报 / 英文图注，三选一作为本学期「被指导」的刻意练习，不要三个一起完美。

## 五、和数字导师怎么用这本手册

直接说例如：

- 「我入学 6 周了，对照手册看我学徒期过没过」
- 「这周没数据，帮我写一页诚实周报」
- 「组会 8 分钟，预审我的页标题像不像结论」
- 「别人讲的时候我该问什么」
- 「开题后出路暗线该占几小时」

它会骂空话、要证据、要你自己填数字。交学校和见导师的终稿仍是你的。
