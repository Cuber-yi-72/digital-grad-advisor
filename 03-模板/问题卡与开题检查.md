# 开题预审清单（数字导师或真人导师勾）

- [ ] 问题能用一句说完，不是「探究…的影响」
- [ ] 创新点属于机制 / 工艺窗口 / 结构器件 / 方法 / 工程 之一，且可检验
- [ ] 对照成立
- [ ] 主路径可在剩余学制内做完 60% 以上
- [ ] 有决策点与备路，不是直线幻想
- [ ] 文献按路线评，不是年代流水账
- [ ] 预期成果对齐培养方案，不写空头顶刊
- [ ] 安全与 SOP 已考虑
- [ ] 与组内课题不撞车或已谈过分工
